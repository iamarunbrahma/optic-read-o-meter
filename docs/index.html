What it does, in one sentence.

Counts the words in a post, divides by reading speed, and prepends a small “3 min read” badge above the content. That’s the whole plugin.

Zero configuration

Activate and your single posts get a tasteful badge above the content. Done.

Five styles included

Pill, minimal, dark, outline, or no styling at all. Switch with one dropdown.

Your colours

Two WordPress color pickers for text and background. Hex codes accepted.

Your wording

“3 min read”, “About 5 minutes”, or whatever you like. Custom template field.

Shortcode + filters

Use [optrom_reading_time] anywhere. Hook optrom_words_per_minute and optrom_label for full control.

No tracking, no CDN

No external HTTP, no third-party libraries, no analytics. Plain PHP and CSS.

Five styles, two-click switch.

Match the badge to your theme without writing a line of CSS.

Get it in under a minute.

Two ways. Pick whichever you have hands on.

From WordPress.org

  1. Go to Plugins → Add New.
  2. Search for Optic Read-O-Meter.
  3. Click Install, then Activate.
  4. Visit Settings → Optic Read-O-Meter if you want to tweak.

Manual zip

  1. Download the latest optic-read-o-meter.zip.
  2. WordPress → Plugins → Add New → Upload Plugin.
  3. Pick the zip, click Install Now.
  4. Activate. Done.

For developers.

Two filters and a shortcode, all you need to ship reading time anywhere.

// Render the label as text:
[optrom_reading_time]

// Render the styled badge:
[optrom_reading_time format="badge"]

// Custom template (the %s becomes the minute count):
[optrom_reading_time template="About %s"]

// PHP filter: change reading speed for technical posts:
add_filter( 'optrom_words_per_minute', function( $wpm, $post ) {
  return has_category( 'technical', $post ) ? 150 : $wpm;
}, 10, 2 );

// PHP filter: replace the entire label string:
add_filter( 'optrom_label', function( $label, $minutes, $post ) {
  return sprintf( '☕ %d min read', $minutes );
}, 10, 3 );
